# 四人八周实施计划与验收

当前实现与实测分别见 [implementation.md](implementation.md) 和 [结果汇总](../../results/det/summary.md)。本表是团队后续复验、接手与扩展的工作量计划，不作为既有贡献记录。

每格约一人周，合计32人周；默认每人每周5个工作日。现有检测实现作为接手起点，所有成员第1周必须亲自跑通并理解所接手模块。工作量包含设计、实现、单测、交叉评审和实验；不以代码行数计贡献。A/B/C/D为待填姓名的角色，不是已完成贡献。

## 1. 每周任务表

| 周 | A：SoC/系统 | B：调度/搬运 | C：阵列/定点 | D：模型/软件 | 周验收门槛 |
|---|---|---|---|---|---|
| W1 | 复验SoC；内存与CPU/DMA分类流量设计；定义ROI | 两模型融合子图审计；双源坐标/ORDER/容量与描述符设计 | 部分和与输入/输出两条重定标通路规格 | 固定两模型与融合位置；浮点图、M/F量化等价参考设计 | 冻结接口含I9和融合子描述符；两模型各至少1处可融合路径 |
| W2 | 大容量延迟内存/BFM；仿真吞吐预算；ROI计数冒烟 | CSR/描述符、直接取数DMA；fusion_mapper行为模型 | 部分和恢复、fake core；I9独立输入转换器 | 两模型主机定点图；CPU物化参考、独立映射参考与随机向量 | 替身交付；主机M/F逐元素相同；固定仿真预算 |
| W3 | 新MMIO/CPU驱动；双主争用；计数准确性测试 | 直接滑窗基线、输出打包；融合坐标与跨源通道分段 | P缓冲、输出量化；I9握手/极值/背压测试 | CPU池化/切片/上采样/拼接；M/F双内存图 | 普通卷积至少100组、融合子图至少50组主机参考；I9数值通过 |
| W4 | 真实CPU单层及融合小子图；长等待/复位测试 | 单bank分块缓冲；I9接入、低路2×复制散写 | 真实核心与融合输入联调；跨Cin块/尾通道修复 | 两模型融合描述符生成；主模型解码/NMS与检查点 | 真实CPU普通卷积与融合小子图逐元素一致；X容量/无虚拟张量写入通过 |
| W5 | M/F子图ROI计时/流量；RAM综合策略 | 单bank融合收口；两种ORDER、halo、跨源Tic尾块 | 输入/输出量化与P完整层覆盖；资源测量 | 主模型整网定位；500张精度；M/F量化与图调度审计 | 主模型真实融合层通过；M/F相同输出、流量口径一致 |
| W6 | 主模型B0/M/F完整RTL长回归 | 融合死锁/地址修复；重复读取与子图流量分析 | 整网数值定位；输入转换开销与波形 | 主模型完整融合检测图；第二模型固件图 | 主模型至少1张完整M/F检测，全层一致；不分配U/C中间张量 |
| W7 | 第二模型M/F同RTL长回归；两模型ROI统计 | 两模型分块选择与融合消融；有余量才做双bank | 两模型I9/核心覆盖收口；有余量配合双bank | 第二模型精度、检测和检查点；峰值内存审计 | 第二模型至少1张完整M/F；同RTL哈希、各1处真实融合子图 |
| W8 | 全回归、M/F综合、干净环境复现与打包 | 冻结融合/调度接口、访存分析；可选双bank结果 | 冻结数值规格、资源/转换开销报告、演示 | 汇总精度/周期/内存/可视化、软件与贡献记录 | 两模型融合验收、M/F消融、原始日志与复现文档 |

W1/W2期间四人并行设计；W3起各模块用替身先验，不等待其他模块全部完成。每周一次接口评审（约1小时）和一次全量集成；每天提交可复现实验记录。集成失败由接口两端共同处理，A不承担全部缺陷修复。

融合作为主线替换原来双bank重叠的必做工作，并未增加总投入。双bank容量仍预留，重叠调度仅在核心验收完成后开展；普通卷积缓存消融缩为代表层实验。

## 3. 强制里程碑与风险处理

| 检查点 | 不通过的含义 | 处理动作 |
|---|---|---|
| W1模型算子审计 | 现有能力无法覆盖图或权重不可复现 | 冻结前解决模型/权重版本、软件算子、解码规则；不能拖到RTL完成后才换网络 |
| W2两模型定点M/F等价 | 数值、concat尺度或解码尚不可信 | D优先解决首个不一致层，C继续随机算子；暂不追求速度 |
| W2仿真预算 | 完整模型长回归超出剩余时间 | 关闭逐拍波形/verbose，优化测试平台与构建，安排夜间回归；仍保留完整RTL单图证据 |
| W4真实单层/融合小子图 | 模块边界或存储协议未闭合 | 四人优先集成，暂停参数扫描和双bank扩展，优先I9与单bank融合，不扩展算子范围 |
| W6主模型完整检测 | 存在正确性/性能集成问题 | 取消双bank、更高分辨率和额外阵列实验，保留两模型融合、M/F基线与正确性 |
| W7第二模型 | 可配置融合尚未证明 | 用逐层清单定位硬编码；不得把少数层跑通写成整模型支持，也不能关闭融合后声称融合可迁移 |
| W8性能目标未达 | 正确性达标但收益不足 | 如实列出消融、瓶颈和负结果；不虚报达成，不替换不公平基线 |

校准后精度不达标时，依次检查BN折叠、输入规范、分支尺度、累加范围、检测头量化和解码；需要重新校准或QAT时单独估算，不把从头训练两模型放入默认32人周。

## 4. 最终交付清单

- 可配置RTL与完整SoC，检测回归保持通过；新增spec自动生成与版本检查。
- 独立核心/调度/总线测试、固定随机种子、断言、失败用例和watchdog。
- 两模型固定版本导出器、manifest、量化参数、图调度及CPU后处理；权重获取说明，不无许可打包第三方资产。
- M/F两套内存图与峰值、40KiB本地SRAM和≤64B融合暂存FIFO预算；无完整U/C分配/写入证据。
- 两模型M/F完整RTL检测、融合层逐元素等价、至少50组双源随机向量、主机各10张可视化、500张精度。
- 主模型B0/M/F、第二模型M/F周期与访存消融；CPU/DMA分类ROI、融合子图与整网收益、输入转换额外资源；双bank为可选项。
- 更新后的框图、接口、操作指南、已知限制、每周真实贡献与交叉评审记录。
